# BMI Calculator & Health Tracker

A Python-based desktop application that calculates BMI, stores BMI records, tracks history, and visualizes BMI trends.

## Technologies Used

- Python
- Tkinter
- SQLite
- Matplotlib

## Features

- Calculate BMI using height and weight
- BMI category classification
- Input validation and error handling
- Store BMI records using SQLite
- View overall BMI history
- Visualize BMI trends using Matplotlib
- Clear input fields
- Simple and user-friendly GUI

## BMI Calculation

BMI is calculated using:

BMI = Weight (kg) / Height² (m²)

## Database

The application uses SQLite to store:

- User name
- Weight
- Height
- BMI
- BMI category
- Date and time
